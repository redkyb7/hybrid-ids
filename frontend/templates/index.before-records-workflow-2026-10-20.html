      THE HYBRID APPROACH

      From network traffic to evidence

      Follow the five stages to see how machine learning triage and deep learning classification turn a flow into a saved result.

      How a flow becomes an alert

      Select a step

      Choose any step to see what it does to a flow.

      01 / TRIAGE

      Focus deeper analysis

      Stage 1 screens each flow. Low-risk flows stop here; flows that need closer examination continue to the deep learning model.

      02 / CLASSIFY

      Make detections understandable

      Stage 2 names the traffic class and records model confidence. Unknown attack remains visible when a class cannot be named confidently.

      03 / INVESTIGATE

      Keep evidence traceable

      Source, target, time and model verdicts connect every displayed detection to a saved flow you can inspect.
