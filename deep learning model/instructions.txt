DEEP LEARNING SOURCE
====================

The current Docker runtime loads the uploaded DL artifact from
updated_models/extracted/dl and passes its paths to predict.NIDSClassifier.
The saved_model/ directory beside this source is a local training output and
is excluded from Git.

To train the DL model, install requirements.txt from this directory and run
train.py from this directory. config.py reads
clean_data/cic-collection.parquet at the repository root and writes artifacts
to this directory's saved_model/. The ML training script is
ml-model-updated.py at the repository root. These independent runs do not
measure the combined ML-to-DL decision rule. Validate the feature schema and
full pipeline before replacing the deployed artifacts.
